# 🎵 리코더 성장 일지 (Recorder Growth Journal) 구현 계획안

초등학교 교사와 학생을 위한 웹앱으로, 학생들이 리코더 연습 과정을 1~2분 안에 즐겁게 기록하고 스스로의 성장을 확인하며, 교사는 학생별 현황 파악과 따뜻한 피드백을 전달할 수 있는 GitHub Pages 정적 웹 애플리케이션입니다.

---

## ⚠️ 필수 조건 충돌 지점 및 검토 결과

> [!IMPORTANT]
> 기획 내용 중 서로 상충하거나 해석이 필요한 3가지 지점을 명확히 정리하고 권장 해결책을 제시합니다.

1. **학생 본인 인증 vs 외부 로그인·비밀키 금지 충돌 (동작 33번 vs 기술 경계)**
   - **충돌 내용**: 동작 33번에서는 *"다른 학생의 기록에 접근하지 못하도록 이름이나 번호 선택만으로는 본인 인증이 완료되지 않아야 한다"*고 명시하였으나, 기술 경계에서는 *"비밀키·로그인 기능을 임의로 추가하지 않는다"*고 제한하고 있습니다.
   - **해결 방안 (권장)**: 외부 계정 로그인 없이 학생 프라이버시를 지킬 수 있도록 **[학생별 4자리 간이 핀(PIN) 번호]** (예: 교사가 부여한 기본 번호 또는 본인이 정한 4자리 숫자)를 입력받아 확인하는 경량 인증 방식을 적용합니다. 또한 학생용 개인 태블릿인 경우 최초 1회 인증 후 해당 기기에 학생 정보가 자동 유지(Remember me)되도록 처리합니다.

2. **연습 횟수 입력 방식 (화면 3 vs 동작 9 & 완료 검사 3)**
   - **충돌 내용**: 화면 3에서는 `+, - 버튼으로 횟수 선택`으로 기술되어 있으나, 동작 9와 완료 검사 3에서는 `'연습 1회 완료!' 버튼을 누를 때마다 누적 + '잘못 눌렀어요' 버튼으로 취소`로 기술되어 있습니다.
   - **해결 방안 (권장)**: 두 방식을 통합하여, 초등학생이 리코더를 한 번 연주하고 큼직하게 탭할 수 있는 **[🎵 연습 1회 완료! (+1)]** 메인 버튼과 오입력 방지용 **[↩️ 잘못 눌렀어요 (-1)]** 버튼을 전면에 두고, 그 옆에 숫자를 1회 단위로 조절할 수 있는 **[+] / [-] 스텝퍼**를 함께 배치하여 완벽히 호환되도록 구성합니다.

3. **구글 스프레드시트 연동 전 및 오프라인 환경 동작**
   - **해결 방안**: 아직 구글 스프레드시트 Web App URL이 연결되지 않았거나 인터넷이 일시적으로 끊긴 상태에서도 웹앱이 멈추지 않도록 **브라우저 로컬 저장소(localStorage)에 1차 즉시 저장**하고, 스프레드시트 Web App URL이 등록되어 있으면 실시간 비동기 전송(fetch)하는 **이중 안전 보관 구조**를 채택합니다.

## 1. 개요 및 핵심 개념 (Overview & Core Concept)

- **앱 명칭**: 🎵 나의 리코더 성장 일지
- **대상 사용자**: 초등학교 담임교사 및 초등학생 (3~6학년)
- **핵심 가치**:
  - **1~2분 간편 기록**: 태블릿 터치 몇 번으로 연습곡, 집중 영역, 횟수, 자기평가 완료
  - **비교 없는 개인 성장**: 타인과의 순위 경쟁 대신 자신의 이전 기록 대비 향상도(누적 일수, 곡별 단계)를 직관적으로 시각화
  - **교사-학생 소통**: 교사가 학생별 연습 상태를 확인하고 따뜻한 격려 피드백을 전달
  - **가벼운 운영**: GitHub Pages 정적 호스팅(index.html, style.css, script.js)과 구글 스프레드시트 무료 데이터베이스 활용

## 2. 사용자 경험 및 화면 구성 (User Experience & Screen Design)

순수 HTML/CSS/JS 기반의 단일 페이지 애플리케이션(SPA) 구조로, 페이지 새로고침 없이 부드러운 뷰 전환을 제공합니다.

### 7개 화면 상세 흐름
```
[1. 시작 화면]
   │
   ├─► [선생님 모드] ──► [6. 교사 대시보드] ──► [7. 교사 관리 화면 (명단/곡/시트연동)]
   │
   └─► [학생 모드] (학급/번호 선택 + 간이확인)
           │
           ▼
     [2. 학생 홈 화면] (환영 인사, 이번 주 연습일, 누적 횟수, 최근 기록 3개)
           │
           ├─► [3. 오늘의 연습 기록] ──► [4. 연습 완료 축하] ──► [5. 나의 성장 기록]
           │                                                        ▲
           └────────────────────────────────────────────────────────┘
```

1. **시작 화면 (`#view-start`)**:
   - 밝은 파스텔 톤의 환영 배너 및 리코더 캐릭터 아이콘
   - [학생으로 시작하기] / [선생님 모드] 분기 버튼
   - 학생 선택: 학급 드롭다운 → 번호 선택 → 이름 자동 표시 → 4자리 확인 코드 입력
   - "이 태블릿에 내 정보 기억하기" 체크박스 제공 (개인 태블릿 최적화)

2. **학생 홈 화면 (`#view-student-home`)**:
   - 상단 헤더: "🎶 [홍길동] 학생, 오늘도 멋진 소리를 만들어봐요!" + 로그아웃/변경 버튼
   - 핵심 지표 카드 3종: 
     - 📅 이번 주 연습: `N일`
     - 🎺 연습한 곡: `N곡`
     - 🌟 누적 연습: `N회`
   - 현재 연습 중인 곡 및 연습 단계 카드 ("할아버지의 낡은 시계 - 3단계 전체 연주")
   - 초대형 메인 액션 버튼: **[ 🎵 오늘 연습 기록하기 ]** (산뜻한 민트/옐로우 그라데이션)
   - 보조 액션 버튼: **[ 📈 나의 성장 기록 보기 ]**
   - 최근 연습 기록 3개 요약 카드 (날짜, 곡명, 횟수, 자기평가 이모지)

3. **오늘의 연습 기록 화면 (`#view-practice-form`)**:
   - ① **오늘 연습한 곡**: 교사가 등록한 곡 목록 드롭다운 (선택 시 현재 권장 단계 뱃지 노출)
   - ② **집중해서 연습한 부분**: 5가지 큰 버튼형 라디오 (운지법 / 호흡 / 박자 / 음 연결 / 곡 전체)
   - ③ **연습 횟수 카운터**: 
     - 대형 카운트 디스플레이 ("5 회")
     - `[🎵 연습 1회 완료! (+1)]` 초대형 탭 버튼
     - `[↩️ 잘못 눌렀어요 (-1)]` 보조 버튼
     - `[-]` / `[+]` 미세조절 스텝퍼
   - ④ **오늘의 자기평가**: 3가지 감정 카드 (😄 목표한 부분을 잘 연주했어요 / 🙂 조금씩 나아지고 있어요 / 😐 연습이 더 필요해요)
   - ⑤ **오늘의 연습 한마디**: 부드러운 텍스트에어리어 (선택 사항, "어려웠던 계이름이나 잘된 점을 적어보세요")
   - 하단: **[ 💾 연습 기록 저장하기 ]** (제출 중 중복 클릭 방지 로딩 스피너)

4. **연습 완료 축하 화면 (`#view-complete`)**:
   - "🎉 오늘도 한 걸음 성장했어요!" 축하 배너 및 반짝이 효과
   - 방금 기록한 연습 요약 카드 (곡명, 횟수, 집중 영역, 평가)
   - [📈 나의 성장 기록 바로보기] 및 [🏠 홈으로 돌아가기] 버튼

5. **나의 성장 기록 화면 (`#view-student-growth`)**:
   - 다른 학생과의 비교 배제, **오직 나의 이전 기록과의 발전 비교**
   - 지표: 총 누적 연습 일수(동일 일자 중복 제거), 총 누적 횟수, 도전한 곡 수
   - **주간 연습 그래프**: 최근 7일간의 일별 연습 횟수 막대그래프 (순수 CSS Flex Bar)
   - **곡별 연습 단계 현황**: 곡마다 4단계 진행 바 (1. 악보와 운지 → 2. 부분 연습 → 3. 전체 연주 → 4. 표현하며 연주)
   - **날짜별 타임라인**: 이전 연습 회차별 카드 (날짜, 집중 영역, 횟수, 자기평가, 소감)
   - **선생님 피드백 카드**: 교사가 남겨준 코멘트가 있을 때 강조 표시 + [확인했어요 👍] 버튼

6. **교사 대시보드 화면 (`#view-teacher-dashboard`)**:
   - 전체 학생 수 대비 이번 주 기록 제출 학생 수 및 참여율(%)
   - 학급 전체에서 가장 많이 연습한 곡 & 가장 어려워하는 연습 요소(운지, 호흡 등) 통계 칩
   - **학생별 연습 현황 테이블**: 학급, 번호, 이름, 총 연습일수, 최근 연습곡, 최근 자기평가
   - 학생 행 클릭 시 해당 학생의 전체 기록 모달 팝업 및 **선생님 피드백 입력 폼** 제공

7. **교사 관리 화면 (`#view-teacher-manage`)**:
   - 탭 1: **학생 명단 관리** (학생 추가/수정, 학급/번호/이름/PIN)
   - 탭 2: **연습곡 관리** (곡 추가/수정, 기본 단계 설정)
   - 탭 3: **기록 관리** (학생의 오입력 기록 수정/삭제)
   - 탭 4: **구글 시트 연동 설정** (Apps Script Web App URL 입력, 연결 테스트 버튼, 상태 뱃지)

### 디자인 시스템
- **색상 팔레트**: 따뜻하고 편안한 소프트 파스텔 톤
  - 주조색 (Primary): 민트/세이지 그린 (`#38B2AC`, `#E6FFFA`)
  - 포인트색 (Accent): 따뜻한 레몬 옐로우 & 소프트 코랄 (`#F6AD55`, `#FED7D7`)
  - 배경색 (Background): 부드러운 크림 아이보리 (`#F7FAFC`, `#EDF2F7`)
- **타이포그래피**: 초등학생의 가독성을 고려한 둥글고 큼직한 서체 크기 (기본 본문 16~18px, 버튼 20px 이상)
- **터치 영역**: 태블릿 환경에 맞춘 최소 48px 이상의 넉넉한 터치 패딩

## 3. 핵심 규칙 및 기술 결정 (Key Technical Decisions)

| 결정 사항 | 채택 방식 | 선정 이유 |
|---|---|---|
| **파일 구조** | `index.html`, `style.css`, `script.js` 3개 파일 분리 | 사용자 요구사항 준수, GitHub Pages 무빌드 직접 배포 가능 |
| **외부 라이브러리** | 순수 Vanilla JS & CSS (Zero Dependency) | 빌드 도구 의존성 제거, 장기 유지보수 및 초보 교사 접근성 극대화 |
| **안전한 데이터 렌더링** | `element.textContent` 및 DOM API 전면 적용 | `innerHTML` 지양으로 XSS 취약점 및 악의적 스크립트 차단 |
| **스프레드시트 연동** | Google Apps Script Web App (JSON POST/GET) | 별도 유료 DB나 서버 없이 교사 개인 구글 드라이브로 영구 보관 |
| **오프라인/에러 대응** | localStorage 1차 저장 + 네트워크 전송 | 와이파이 단절 시 작성 데이터 유실 방지, 재접속 시 동기화 |
| **연습 일수 계산** | 고유 날짜(Date String) Set 기반 카운트 | 하루에 3번 기록해도 누적 연습 일수는 '1일'로 정확히 계산 |

```
┌─────────────────────────────────────────────────────────────┐
│                   클라이언트 브라우저 (태블릿/PC)                │

│       ▲                                                     │
│       │ DOM 렌더링 & 이벤트 처리                               │

│       │                                                     │

│   - doPost(e): 연습기록 추가, 피드백 등록, 학생/곡 관리        │

                        │ SpreadsheetApp API
                        ▼

│  [시트 1: 학생명단]                                          │
│   - 학생ID | 학급 | 번호 | 이름 | 확인코드 | 등록일자           │
│                                                             │
│  [시트 2: 연습곡목록]                                        │
│   - 곡ID | 곡명 | 연습단계 | 정렬순서                           │
│                                                             │
│  [시트 3: 연습기록]                                          │
│   - 기록ID | 일시 | 학생ID | 곡명 | 연습목표 | 연습횟수 |       │
│     자기평가 | 소감 | 교사피드백 | 학생확인여부                 │
└─────────────────────────────────────────────────────────────┘
```

### 제공 파일 목록
1. `index.html`: 시맨틱 마크업 기반 7개 뷰 뼈대
2. `style.css`: 태블릿 반응형, 파스텔 감성 스타일, 넉넉한 버튼 레이아웃
3. `script.js`: 상태 관리, 뷰 라우팅, 유효성 검증, 로컬 저장 및 Apps Script 통신
4. `setup.md`: 구글 스프레드시트 템플릿 생성 및 Apps Script 배포 단계별 매뉴얼

## 5. 이번 버전에서 제외할 기능 (Out of Scope)
- ❌ 학생 간 랭킹, 등수, 포인트 경쟁 시스템 (성장 중심 교육 철학 준수)

## 6. 직접 실행할 단계별 검사 절차 (Verification Plan)

### A. 학생 모드 및 기록 검사
1. **정상 입력 - 학생 로그인 및 세션 확인**
   - 절차: 학급(3학년 1반), 번호(1번), 이름 확인 후 입장
   - 기대 결과: 학생 홈 화면으로 전환되며 상단에 학생 이름과 이번 주 연습일수가 표시됨
2. **예외 입력 - 학생 미선택 시 방어**
   - 절차: 학급이나 번호를 고르지 않고 시작 버튼 클릭
   - 기대 결과: 다음 화면으로 이동하지 않고 부드러운 경고 안내 메시지 노출
3. **정상 입력 - 카운터 누적 및 감소**
   - 절차: [연습 1회 완료!] 버튼 3회 클릭 후 [-1 잘못 눌렀어요] 1회 클릭
   - 기대 결과: 연습 횟수가 정확히 2회로 표시됨
4. **예외 입력 - 카운터 음수 방지**
   - 절차: 횟수가 0인 상태에서 [-] 또는 [-1 잘못 눌렀어요] 클릭
   - 기대 결과: 0 미만으로 내려가지 않고 0으로 유지됨
5. **예외 입력 - 필수 항목 누락 방지**
   - 절차: 자기평가(이모지)를 선택하지 않고 [연습 기록 저장하기] 클릭
   - 기대 결과: 저장이 차단되고 "오늘의 자기평가를 선택해주세요" 강조 표시
6. **정상 입력 - 연습 기록 저장 및 완료**
   - 절차: 필수 항목 모두 입력 후 저장 클릭
   - 기대 결과: 저장 버튼이 일시 비활성화되어 중복 등록이 방지되고 완료 축하 화면으로 전환
7. **계산 규칙 검증 - 동일 날짜 연습 일수 중복 방지**
   - 절차: 같은 날짜에 연습 기록을 2회 이상 연속으로 저장
   - 기대 결과: 누적 연습 횟수는 합산되나, 누적 연습 일수는 1일로 정확하게 계산됨

### B. 교사 모드 및 관리 검사
8. **교사 인증 및 대시보드 조회**
   - 절차: 교사 모드 선택 → 관리자 PIN 입력 → 대시보드 진입
   - 기대 결과: 학생들의 연습 현황 목록과 통계 카드가 정상 로드됨
9. **교사 피드백 작성 및 학생 확인**
   - 절차: 특정 학생 기록에 "호흡이 많이 좋아졌어요!" 피드백 입력 후 저장
   - 기대 결과: 학생의 성장 기록 화면에 해당 피드백이 표시되고 [확인했어요 👍] 버튼 동작
10. **스프레드시트 연동 및 가이드 검사**
    - 절차: `setup.md`에 명시된 절차대로 배포 후 테스트 URL 입력
    - 기대 결과: 연동 상태 뱃지가 '연결됨(초록)'으로 갱신되고 데이터 송수신 성공
